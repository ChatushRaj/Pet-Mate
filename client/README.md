# PetMate — Client

React frontend for PetMate. See the [root README](../README.md) for full setup instructions (database, environment variables, running both client and server together).

## Quick reference

```bash
npm install
npm start    # http://localhost:3000
npm run build
```

Set `REACT_APP_API_URL` in a `.env` file (see `.env.example`) if the backend isn't running on `http://localhost:9800`.
